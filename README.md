# Hola, soy Joako 👋

Soy desarrollador principiante en formación, con interés en el desarrollo web. Uso este perfil para compartir ejercicios y prototipos que forman parte de mi aprendizaje.

## Proyectos destacados

- [Extintor](https://github.com/JoakoLionel/Extintor): prototipo web para registrar extintores mediante QR, código de barras, OCR o carga manual. Guarda registros localmente, permite exportarlos a Excel y ofrece envío opcional a Google Sheets.
- [Asistencia 6-3ra](https://github.com/JoakoLionel/asistencia-6-3ra): prototipo web de asistencia con QR temporal, validación de ubicación y panel docente.
- [TOPOGRAFICO](https://github.com/JoakoLionel/TOPOGRAFICO): prototipo interactivo de práctica con modos visuales para ángulos, coordenadas y pendiente.
- [Ejercicios de Processing](https://github.com/JoakoLionel/Programaci-n-sobre-redes): colección de ejercicios y prácticas de programación visual.

## Tecnologías que aparecen en mis repositorios

- HTML, CSS y JavaScript para prototipos web.
- Processing en ejercicios de programación.
- A-Frame y AR.js en demos de realidad aumentada.
- Google Apps Script y Google Sheets en integraciones de algunos prototipos.

Sigo aprendiendo y mejorando mis proyectos paso a paso. El alcance y el estado de cada trabajo corresponden a lo que está publicado en su repositorio.
